# Portal Ferramentas — versão 2

Site estático em HTML, CSS e JavaScript, sem dependências externas.

## Publicação na Cloudflare Pages

1. Envie **o conteúdo desta pasta** para a raiz do repositório GitHub `portal-ferramentas` (substitua o `index.html` anterior).
2. Confirme que `index.html`, `assets/`, `ferramentas/`, `sobre/`, `privacidade/` e `contato/` estão diretamente na raiz do repositório.
3. Faça commit na branch `main`.
4. A Cloudflare Pages conectada ao GitHub deve atualizar o site automaticamente.

**Configuração do Pages:** Framework preset: None; Build command: vazio; Build output directory: `.` (ponto).

## Recursos

12 ferramentas funcionando, busca e categorias, páginas individuais, layout responsivo, metadados SEO, sitemap e robots.txt.

## Antes de solicitar AdSense

Revise os textos institucionais, ofereça conteúdo realmente útil e original, confirme as políticas de privacidade e adicione instruções de anúncios/consentimento conforme exigidas pelo AdSense. **Não existe aprovação garantida.**

## Teste local (opcional)

Na pasta do projeto, execute `python -m http.server 8000` e abra `http://localhost:8000`.
