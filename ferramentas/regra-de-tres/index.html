Sobre esta ferramenta

Preencha três números para descobrir o quarto valor em uma proporção direta: se A corresponde a B, então C corresponde a X. Resolva proporções diretamente proporcionais.

Dica para obter um resultado correto

Para proporção direta, X = (B × C) ÷ A. A regra de três inversa exige outra fórmula.
